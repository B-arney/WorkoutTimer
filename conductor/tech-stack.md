# Technology Stack

## Core Language & Frameworks
- **TypeScript:** Primary language for type safety.
- **React Native (Expo):** Mobile app framework.
- **NativeWind:** Styling using Tailwind CSS utility classes.

## State Management & Routing
- **Zustand:** Global state management for workout tracking.
- **Expo Router:** File-based routing for navigation.

## Data & Storage
- **Firebase Firestore:** Primary cloud backend database for cross-device data persistence.
- **Expo SQLite:** Local, on-device database storage for custom routines and history.

## Testing & Tooling
- **Jest:** Testing framework.
- **React Native Testing Library:** UI testing for React components.
