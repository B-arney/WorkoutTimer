# Initial Concept
Időmérő alkalmazás edzésekhez (Workout Timer Application).

# Target Audience
**Fitness Enthusiasts:** Designed for individuals performing High-Intensity Interval Training (HIIT), Tabata, or circuit training who require customizable intervals.

# Core Features
- **Custom Routines:** Save and load complex interval sets.
- **Categorization:** Group workout plans using a robust Category system.

# App Experience / Flow
- **Quick Start:** The main user flow prioritizes a quick start approach, allowing users to start a default or their last-used timer with a single tap.
